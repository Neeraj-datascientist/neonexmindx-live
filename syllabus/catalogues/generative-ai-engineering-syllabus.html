Module 72: PART D

Project Studio & Technical Defense

Minimum evidence for the final project review
  • Problem statement, target user, scope, constraints and acceptance criteria.
  • Architecture diagram and rationale for the selected model/provider, data layer, retrieval/tools, state and deployment approach.
  • Version-controlled repository, setup instructions and explanation of significant code.
  • Test set and evaluation results, including at least one documented failure case and improvement.
  • Security/threat model covering data boundaries, credentials, prompt injection and tool permissions as applicable.
  • Deployment or reproducible execution, operational notes, known limitations and recovery/runbook.
  • Live technical defense: demonstrate the system, explain trade-offs and answer questions about code, tests and failure modes.
