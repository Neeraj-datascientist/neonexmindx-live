# NeoNeX MindX - Courses Module

Welcome to the **Courses** directory.

## Purpose
This directory houses course curricula, syllabi, training modules, batch assignments, and course asset files for NeoNeX MindX training programs.

## Linked CRM Modules
- **Batches & Schedules:** Linked to the Courses & Batches tab in the CRM.
- **Fees & Invoicing:** Linked to Course Fee structures and student invoicing.
- **Student Enrollments:** Automated assignment of registered leads into upcoming course batches.
